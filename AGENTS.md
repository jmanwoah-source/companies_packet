## Hard rules

1. **One wiki root.** `/home/jaren/wiki` is the only live root. Never create a tree under `~/.hermes/cron/wiki/`. The health gate fails on `~/wiki/entities` reappearing (split-drift sentinel).
2. **raw/ is read-only.** Ingested sources are never edited or deleted after landing.
3. **Companies are tickers.** A dossier is named by its canonical symbol (`NVDA.md`, or `NVDA/NVDA.md` when a directory container exists). Prefer the directory form `companies/<T>/<T>.md` when it exists.
4. **Dossier writes:** the deterministic pipeline engine (`pipeline_engine.py` `wiki_note_path()`) owns catalyst-note appends. LLM agents may append dated catalyst notes and update headers but must not reformat the `### Dated Catalyst Notes:` block or duplicate brief lines (dedup key = normalized line, 140-char prefix, timestamps normalized).
5. **Archive, never delete.** Demotions move the dossier file to `archived/` (rename dir if directory form). Restores go back to `companies/`.
6. **Market-cap policy:** soft ceiling band **$500M to $300B** (floor ~$500M for tradable common equity; band $200B-$300B allowed + flagged `near_ceiling`; >=$300B drop; null-CIK = fund, drop). Do NOT reject tickers for exceeding ~$100B — that was a stale value; the ceiling is $300B.
7. **Watchlist outputs** (golden/emerging/mirage) are generated by `tier_lists.py` from `~/.hermes/cron/tier_list_state.json` — agents must not hand-edit the tier files except via that script.
8. **Append-only log.** Every structural operation gets a dated entry in `log.md` (latest 50 kept).
9. **No scratch files** in the wiki tree. Scratch lives under `/tmp/`.
10. **Git.** The tree is a git repo. Commit structural changes with a descriptive message after each migration phase; do not commit mid-run.

## Sub-agent timeout protocol (learned 2026-10-22)

The delegate_task children hit the 600s hard timeout on a research+write combo (backend ~50s per web call). Rules that keep them under budget:
- **Pre-research inline:** gather financials via web_search in the parent turn BEFORE dispatching; pass the data in `context` so children only write files.
- **Max 3 web searches per child** and **max 4 files per child**. More work = more parallel children, not a bigger single child.
- **Never dispatch a child that must both research AND write >4 files** — that combo exceeds 600s.
- **On timeout:** salvage the child's transcript research and write the files inline in the parent. The transcript at `~/.hermes/cache/delegation/live/<id>/task-N.log` retains everything the child gathered.
