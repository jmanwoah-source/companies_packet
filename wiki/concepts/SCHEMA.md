# Tech-Gap Entity Schema (early-advantage wiki)

One file per **technology gap** (a missing technology, process, or hole to fill in the market).
Purpose: surface the ticker that is ONTO SOMETHING before mainstream news, and name the
incumbent that is DOOMED. Karpathy style: short, opinionated, concrete numbers, dated,
linked. Each file MUST be < 60 lines.

## Required sections (in order)

```markdown
# <Tech Gap>                      <- one-line gap name (the hole being filled)

**Thesis.** <What is missing + why it matters now, 1-2 sentences, with a number.>

## Demand
- Who needs it (named buyer / use case). TAM or demand number if available.

## Fillers                          <- companies closing the gap; US tickers only (private = PRIVATE)
| Ticker | Company | Stage | Evidence (dated, linked) | Confidence |
|--------|---------|-------|--------------------------|------------|
Stages: academic | pilot | first_customer | shipping

## Displacement (the DOOMED contrast)
- **Advantaged:** <ticker> — <why it is onto something>.
- **DOOMED incumbent:** <ticker> — <the old process/monopoly it is displacing>. State the contrast explicitly.

## Time-to-fill
- <estimate + the constraint that gates it (NRC, fab capacity, grid interconnect, etc.).>

## Open questions
- <2-3 concrete checks the pipeline should run next cycle.>

## Sources
- [date] <headline> — <url>   (mark VERIFIED vs UNVERIFIED)
```

## Rules
- US-listed tickers only; private companies get `PRIVATE` in the ticker column.
- Every filler and incumbent MUST have a dated, linked source. No unlinked claims.
- `Confidence`: high (primary/company/gov source) | medium (trade press) | low (aggregator).
- The `Displacement` section is MANDATORY — a tech gap with no doomed incumbent is
  additive (new market), not a displacement; say so explicitly if that is the case.
- Stage drives the commercialization score in `inclinations/inclination_score.py`:
  shipping > first_customer > pilot > academic.
- Do NOT delete on demotion. If a filler falls behind, lower its stage + confidence.
